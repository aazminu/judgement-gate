# E2E CI job Implementation Plan

> Spec: `docs/superpowers/specs/2026-10-20-e2e-ci-design.md`. Read it first; this plan only orders the work.

**Goal:** `npm run e2e` drives the demo scenarios through signed webhooks into the real Worker (`wrangler dev`), a scripted Jev and the project's mock GitHub, asserts on what the mock recorded, and runs as its own CI job.

**Constraints:** no `src/` changes; 310 vitest tests and typecheck stay green; demo commands (`mock-github`, `dev`, `simulate`) keep working; no secrets, no network beyond loopback.

## Tasks

1. **Scenario data** (`scripts/scenarios.mjs`). Add `noul`/`choice` helpers and a `jev` answer map per scenario 1-7. Verify: `node -e` import prints the keys; simulate/mock still import it.
2. **Mock recording** (`scripts/mock-github.mjs`). Record checks (with head sha, status, conclusion, title, summary), comments and labels; add `GET /__recorded`, `POST /__reset`, `POST /__register`. Verify: start it, post by hand with curl, read `/__recorded`; console output unchanged.
3. **Jev stub** (`scripts/jev-stub.mjs`). `POST /` answers from the control state; `/__control` get/set; modes `ok|down|badsev`. Verify: curl each mode.
4. **Harness** (`scripts/e2e.mjs`, `package.json` script `e2e`). Free ports, env file, spawn three children, readiness, run cases, bounded polling, teardown on every exit path, expected-vs-actual diff, 120 s overall timeout. Verify: runs green twice; one deliberately wrong expectation fails with a diff and exit 1, then revert.
5. **CI and docs** (`.github/workflows/ci.yml`, `.gitignore`, README, `docs/operations.md`). New `e2e` job; log artifact on failure; ignore `.e2e-logs/`.
6. **Verify and PR.** `npm test`, `npm run typecheck`, `npm run e2e` twice, wrong-expectation run, open PR, wait for CI, hand-over note in the shared notes folder.

## Review focus

- No orphan `wrangler`/`workerd` process after success, failure, timeout or Ctrl-C (check on Windows).
- The user's `.dev.vars` is never touched.
- Polling waits for the check run to complete, not a fixed sleep.
